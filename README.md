# Тайна Ночного Кафе

## Интерактивная 3D игра с диалоговой системой

---

## Описание проекта

Интерактивная браузерная 3D игра в жанре "ночное кафе". Игрок взаимодействует с тремя NPC-персонажами в уютной атмосфере ночного кафе. Каждый персонаж имеет уникальную личность, систему отношений и ветвящиеся диалоги. Выборы игрока влияют на отношения с NPC и открывают различные ветки сюжета.

## Технический стек

| Компонент | Технология |
|-----------|------------|
| 3D рендеринг | Three.js (v0.160.0) |
| Платформа | WebGL (браузер) |
| UI | HTML/CSS/JavaScript (vanilla) |
| Шрифты | Playfair Display, Source Sans Pro (Google Fonts) |
| Запуск | Любой HTTP сервер (python3 -m http.server) |

**Важно:** Для локального запуска требуется HTTP сервер из-за CORS политик браузеров. Direct file:// работает только в некоторых случаях.

### Система NPC

Каждый NPC — это `THREE.Group` со следующими компонентами:

```javascript
npc.userData = {
    id: 'elena' | 'marco' | 'nina',
    name: 'Элена' | 'Марко' | 'Нина',
    personality: 'загадочная' | 'внимательный' | 'нервная',
    currentNode: 'intro',              // Текущий узел диалога
    basePosition: { x, y, z },         // Базовая позиция
    lookAtPlayer: true,                // Следить за камерой
    talking: false,                    // Флаг разговора
    lastTalkTime: 0                    // Время последнего разговора
}
```

### Система диалогов

Диалоги организованы как дерево узлов (dialogue tree):

```javascript
dialogueTree: {
    intro: {
        text: 'Текст диалога...',
        choices: [
            { text: 'Вариант ответа', next: 'greeting', relation: 10 },
            { text: 'Другой вариант', next: 'ignore', relation: -5, requires: 'ключ' }
        ]
    },
    greeting: {
        text: 'Продолжение...',
        effect: { addItem: 'предмет', clue: 'улика', quest: 'задание', unlock: 'локация', vision: 'эффект', found: 'находка' },
        choices: [...]
    }
}
```

#### Эффекты диалогов

| Эффект | Описание |
|--------|----------|
| `relation` | Изменение отношения NPC (-100 до +100) |
| `addItem` | Добавление предмета в инвентарь |
| `clue` | Новая улика (счётчик +1) |
| `quest` | Новое задание |
| `unlock` | Открытие новой локации |
| `vision` | Визуальный эффект (показать скрытое) |
| `found` | Нахождение персонажа/предмета |

#### Условия выбора

- `requires: 'предмет'` — выбор доступен только при наличии предмета в инвентаре
- Если условие не выполнено, кнопка отображается с пометкой "(нужен предмет)" и неактивна

### Игровое состояние

```javascript
gameState = {
    relationships: { elena: 50, marco: 50, nina: 50 },  // 0-100
    inventory: [],                                        // Предметы
    cluesFound: 0,                                        // Счётчик улик
    talkedTo: { elena: false, marco: false, nina: false }, // Флаги разговора
    day: 1,                                               // Игровой день
    ending: null                                          // Выбранная концовка
}
```

## NPC Персонажи

### Элена (загадочная)
- **Позиция:** (-2, 0, 1)
- **Стиль волос:** Случайный (3 варианта)
- **Сюжетная роль:** Знает о подвале и коллекции Маркуса
- **Ключевые улики:** Старинный ключ, схема подвала
- **Концовка:** Может помочь найти подвал

### Марко (внимательный)
- **Позиция:** (2, 0, -1) — у барной стойки
- **Стиль волос:** Случайный (3 варианта)
- **Сюжетная роль:** Бармен, знает основателя кафе
- **Ключевые улики:** Код подвала, фотография основателя
- **Особенности:** Даёт особенный напиток "Память"

### Нина (нервная)
- **Позиция:** (0, 0, 2)
- **Стиль волос:** Случайный (3 варианта)
- **Сюжетная роль:** Ищет Сергея и брошь
- **Ключевые улики:** Амулет защиты, связь с Маркусом
- **Особенности:** Даёт амулет для подвала

## Для ИИ-агентов: Инструкции по разработке

### При продолжении разработки

1. **Читайте этот файл** перед началом работы
2. **Сохраняйте стиль кода** — используйте существующие конвенции:
   - Имена переменных: camelCase
   - Имена классов: PascalCase (для CSS)
   - Отступы: 4 пробела
   - Комментарий на русском языке (для контекста)
   - Функции в функциональном стиле

3. **Структура Three.js кода:**
   ```javascript
   // 1. Инициализация сцены
   function init() {
       scene = new THREE.Scene();
       camera = new THREE.PerspectiveCamera(...);
       renderer = new THREE.WebGLRenderer({...});
       setupLighting();
       createRoom();
       createNPCs();
       // ... events
   }
   
   // 2. Анимационный цикл
   function animate() {
       requestAnimationFrame(animate);
       // обновления
       renderer.render(scene, camera);
   }
   ```

4. **Добавление нового NPC:**
   - Добавить данные в `npcData` объект
   - Добавить визуальное представление в `createNPCs()`
   - Добавить диалоги в `dialogueTree`
   - Обновить UI (npc-status)

5. **Добавление нового диалога:**
   - Добавить узел в соответствующий `dialogueTree`
   - Убедиться, что `next` указывает на существующий узел
   - Добавить эффекты если нужно

6. **Добавление 3D объектов:**
   - Использовать `THREE.Group` для сложных объектов
   - Настроить материалы с `roughness` и `metalness`
   - Включить `castShadow` и `receiveShadow`
   - Добавить в `scene.add()`

7. **Тестирование:**
   - Открывать через HTTP сервер (не file://)
   - Проверять консоль на ошибки
   - Тестировать все ветки диалогов
   - Проверять инвентарь и отношения

### Полезные сниппеты

#### Добавить новый предмет в игру
```javascript

// Добавить иконку (если нужна):
```

#### Добавить новый свет
```javascript
const light = new THREE.PointLight(0xffffff, intensity, distance);
light.position.set(x, y, z);
scene.add(light);
```

#### Добавить анимацию NPC
```javascript
// В animate():
npc.children[0].rotation.y = Math.sin(time * speed + offset) * amplitude;
```

### Частые проблемы и решения

| Проблема | Решение |
|----------|---------|
| CapsuleGeometry не определён | Использовать CylinderGeometry |
| Текстуры не загружаются | Проверить CORS, использовать data URI или inline |
| Тени не работают | Включить renderer.shadowMap, castShadow, receiveShadow |
| Диалог не открывается | Проверить raycaster, mouse coords, gameStarted flag |
| Слишком темно | Увеличить intensity lights или toneMappingExposure |
